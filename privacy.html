Privacy policy

Hermes Homestead · last updated 27 September 2026

Hermes Homestead is a private assistant used by one homestead. Only the homestead's own Google account is connected to it, and only the two members of the homestead use it.

What data it uses

With the account owner's consent, it accesses that Google account's Gmail messages, Calendar events, Drive files, Docs, Sheets and contacts. It uses them only to answer the homestead's own requests and to prepare its scheduled summaries.

Where the data goes

  • The access token and everything the assistant keeps are stored on the homestead's own server and in its encrypted backups.
  • To answer a request, the relevant text is processed by an AI model: Anthropic's Claude through Amazon Bedrock, or models running on the homestead's server. The data is not used to train AI models.
  • The data is never sold, never used for advertising, and never shared with anyone outside the homestead.

Google API Services User Data Policy

Hermes Homestead's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The account owner can revoke the assistant's access at any time at myaccount.google.com/permissions, and can delete what the assistant has stored by removing it from the homestead's server.
